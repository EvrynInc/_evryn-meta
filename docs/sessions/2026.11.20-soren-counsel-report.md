### The two wrong verdicts, and why each sits on the blocker side of the line

**P1: an omitted `--incoming` silently disables D3** (the incoming handoff re-read, one of the audit's named failures: Soren am2's) **and C10's incoming half** (D6).
- **Mechanism:** `begin` treats a missing `--incoming` as "this packout has no incoming". C7 then PASSes on "nothing to re-read", and `verify` agrees, because it takes the arguments from the `begin` row itself.
- **The tell is only in the report's evidence column,** which a seat that sees "12 PASS" will not read.
- **The line:** D11 (*"An honest slip must not weaken the verdict"*) names exactly this class.
- **Fix (P2: make the slip impossible rather than warned about):** require `--incoming <path>` or an explicit `--incoming none`, and refuse a `begin` that has neither. A few lines, a test (P1 → refused), and a mutation row.

**P4: an incoming list path that doesn't resolve is treated as committed.**
- **Mechanism:** C10 resolves each path in the incoming's `## Uncommitted` list against the outgoing handoff's own repo root (`checks.mjs` C10, `abs()`). A path that doesn't exist there gets `isCommitted() === null`, and `null` is skipped silently (`c === false` is false). Two forms reach this:
  - a path prefixed with its repo name, which is the form our writing protocol prescribes for cross-repo paths (*"Cross-repo: `_evryn-meta/docs/hub/roadmap.md`"*);
  - any path in a different repo from the handoff. That is common: AC lanes keep handoffs in the `_evryn-meta` worktree and carry uncommitted files in `evryn-team-workspace`, and the reverse holds for Captains.
- **The outgoing half doesn't have this hole:** its `named()` matches by path suffix, so the same forms are accepted there. The asymmetry is the defect.
- **The line:** a v1 check (C10) giving a false PASS on an honest skip (D6, a predecessor's uncommitted file dropped). That is the Captain's own blocker definition (lane Log, 10:54 Fri), the same class QC5 rated a blocker as Q5-3.
- **Fix:** resolve a listed path against the code root when its first segment names a repo, otherwise against the handoff's repo, and **FAIL loud when a listed path resolves to no repo**, never skip it. A test (P4 → FAIL; P4b and the existing `Q5-3 kept` unchanged), and a mutation row.
