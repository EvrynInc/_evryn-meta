### ✅ A SILENT-FAILURE DEFECT IN THE BRIEF'S OWN DERIVATION SCRIPT — FIXED in the brief by ACT-21 (§12, item 5)

**`§3` of the incoming brief supplies this:**

```bash
grep -m1 "HELD-SESSION-DOC" "$f" | sed 's/...//' || echo "(no banner)"
```

🔴 **The `||` binds to the whole PIPELINE, and `sed` exits 0 on empty input — so the `(no banner)` branch can never fire.** **An unbannered document emits a BLANK LINE, which `sort | uniq -c` then counts as an unnamed category.** ⇒ **The script cannot report the thing it was written to report, and it fails silently.** **It also scans only with `grep -m1` against the whole file, which is correct — the head-window defect above was mine, not its.**

**The fix is to capture first and test the variable:** `owner=$(grep -m1 … | sed …); [ -z "$owner" ] && owner="(NO BANNER)"`. **That is what I used.**
