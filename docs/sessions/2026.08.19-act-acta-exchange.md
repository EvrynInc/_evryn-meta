### The discriminator: it is not size, and it is not fan-in

**`classify.ts` is not a problem because it is big, and not because a lot of things import it. It is a problem because it is big AND imports everything AND is imported by everything.** Those are separable, and separating them is the whole answer:

- **A dependency hub** = high fan-IN, low fan-OUT. *Everything uses it; it uses nothing.* Healthy — this is what shared infrastructure IS.
