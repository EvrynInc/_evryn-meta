## §1 — WHAT THIS CHANGE IS, AND WHY IT MATTERS

**The team runtime composes each agent fresh on every wake** from about thirteen layers — the team manual, the Hub, current-state, the agent's own definition, **its memory**, the thread, and more. **There is no session: everything the agent knows arrives through that composition.**

🔴 **THE DEFECT: memory was the ONLY composed layer that could arrive EMPTY on a read error and tell nobody.** **Identity REFUSES the wake. Current-state PINGS Justin. Memory logged a `console.warn` and the wake proceeded** — producing an agent composed with none of its accumulated judgment, **and no signal to anyone that it had happened.**

🔑 **Why that is the worst of the three, not the least: an agent composed without its memory still SOUNDS like itself.** Identity, spokes and the Hub all loaded. **It is confidently missing everything it has ever learned.** *(The worked example is real: composed without memory, Nathan does not know the company's only hard external deadline exists — and nothing in his wake would tell him anything was absent.)*

**What the change adds: a GRADING LADDER for that layer** — `intact` · `absent` · `damaged` · `refuse` — so the composer can tell *"this agent has no file yet"* (legitimate: a newly stamped-on agent) from *"this file is present and unreadable"* (a defect, every time).

### 🔴 JUSTIN'S RULING — this is the policy you are reviewing against, and it CHANGED after the first build

> **A memory DAMAGED AT REST REFUSES the wake. It does not compose with a flag.**
>
> *His words: "I want this to fail gracefully, but I don't want it to be soft — agents love to go forward with 'yeah, but It's prob okay' when it's totally not. And holes in your memory? No bueno."*

**Sharpened the same day, and the sharpening is the load-bearing half: the refusal comes after ONE RE-READ, never on the first bad read.** *("If it's just a bad load, I don't want anyone crashing if the file is fine.")* 🔑 **There is no network fetch to retry — but the runtime WRITES that file itself, so a compose can race a write and read a half-written one.** **One re-read. No loop. And the refusal message must say that it re-read.**

**What that ruling retired:** the agent-facing *damaged* warning, and the plumbing that carried it. **Under a refusal no agent ever wakes to read it.** **An operator-facing refusal message replaces it.**
**What it did NOT change:** `absent` still composes an explicit notice at a lower grade with a rate-gated alarm; `intact` still raises nothing.
