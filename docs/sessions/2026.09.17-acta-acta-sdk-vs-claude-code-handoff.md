### 3.4 · This environment, first-hand `[R]` — read from the session's own tools

- **Cross-session messaging works; subagent-to-subagent does not.** A subagent's messages go out under its parent's address and replies return to the parent, **so two subagents of one session cannot converse** — separate sessions can.
- **In-session scheduling (`CronCreate`, the `/loop` substrate) dies with the session** — *"nothing is written to disk"*, `durable` has no effect, jobs fire only while the REPL is idle, recurring jobs auto-expire after 7 days. **`Monitor` is likewise session-scoped.**
- **`RemoteTrigger`** lets a session list, create, update and run **cloud Routines** and read each run's log. ⇒ **A local agent can schedule or fire cloud work.**
- **`PushNotification`** reaches his phone **only if Remote Control is connected.**
- 🆕 **`/clear` does NOT clear a session in place — it starts a NEW session and leaves the old one running.** *(Observed 2026-09-17. This corrects the previous handoff, which treated `/clear` as an in-place wipe and left the transcript question open.)* ⇒ **It gives you a fresh instance with no summary at all, while the old session and its transcript stay alive.**
  - 🔴 **AND JUSTIN RULED IT OUT THE SAME DAY: *"the clear slash command is dead for us."*** **His reason: *"I'd much rather have direct access to the subagents — not having to try to harvest stuff over to a new instance."*** ⇒ **A deliberate daytime re-spin uses `/compact`.** **The trade, plainly: `/compact` costs a 5–8K summary and KEEPS this session's subagents resumable; `/clear` saves the summary and forfeits them. The subagents are worth more.**
  - 🔎 **AND IT WAS TESTED, SO THIS IS NOW A FACT RATHER THAN A CAUTION: a `/clear`ed session CANNOT resume the old session's subagents — not even by agentId.** *(Justin, 2026-09-17: he reopened the cleared instance and tried; **"it has no way to resume them — even by their id — the output is just false."**)* ⇒ **Subagent resume is bound to the session that spawned them, and `/clear` leaves that session behind.** **This is the measured basis for the ruling above, not a prediction.**
