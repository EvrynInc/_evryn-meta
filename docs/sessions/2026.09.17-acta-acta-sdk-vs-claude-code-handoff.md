### 3.4 · This environment — **observed first-hand**, from the session's own tools

- **Cross-session messaging works; subagent-to-subagent does not.** A subagent's messages go out under its parent's address and replies return to the parent, **so two subagents of one session cannot converse** — separate sessions can.
