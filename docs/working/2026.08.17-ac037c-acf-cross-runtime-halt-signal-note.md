## The instance that produced it, as evidence rather than as the point

That signature was **deliberate** — it let existing callers keep compiling when the sentinel was introduced. **The cost showed up later:** `src/notify/slack.ts` calls `runEvrynQuery` and **never checks `isHaltSignal`** — zero references in the file. **Two details that make it a good specimen:** the protocol had **already named this failure in the abstract** (*"a new pathway that calls `runEvrynQuery` and forgets `isHaltSignal` will silently treat a halt as a real, empty answer — compile clean, tests green"*) and it happened anyway; and **only one of several call sites checks**, which is exactly what an optional check produces over time.
