# §5 — GOTCHAS LEARNED TODAY. Each one cost real time.

- 🔴 **`grep "Step 93"` returns NOTHING in the sprint doc** — it writes steps as numbered list items (`93.`). **This produced SIX false "lost content" findings** during the loss audit before it was caught. Grep `^93\.` instead. *(The Code Atlas §11 already documents this and it still caught a fresh instance.)*
- 🔴 **You cannot TYPE a control character through these tools.** The Write tool strips it; a JSON tool argument interprets `\uXXXX` into the real character. **Construct it — `String.fromCharCode(0)`.** AC0-37b introduced a NUL into the sprint doc while writing the note about NUL bytes, then could not write a repair script until it stopped trying to type one.
- ⚠️ **A verification grep with a backslash-escaped backtick inside single quotes matches a LITERAL BACKSLASH** and silently returns 0. AC0-37b's first verification of the re-applied sprint lines "passed" this way and meant nothing. **If a check returns exactly the number you hoped for, re-run it a different way.**
- ⚠️ **Node on Windows does not resolve git-bash `/c/...` paths.** Use the scratchpad dir or a relative path.
- ⚠️ **`git commit` during a merge cannot take a pathspec** — it commits the whole index. **If you have unrelated uncommitted work, commit it FIRST or it gets swept into the merge commit.** AC0-37b aborted a merge mid-flight to avoid exactly this.
- ⚠️ **A five-commit rebase means five conflict passes.** For a doc branch where you want the branch's content wholesale, **a single `--no-ff` merge is one controlled resolution instead.**
