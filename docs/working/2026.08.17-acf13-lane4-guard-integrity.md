## §1 — The subject of this lane, stated once because it explains every item

**A guard can be genuine and still not cover what its name claims — and that failure looks healthy from every angle.** This runtime has now produced several: a NUL-byte guard whose scope was a hand-maintained list, and whose anti-vacuity test iterated *that same list*, so it could not see its own gap · three emergency-alert tests that injected a transport and never asserted it was used · a test asserting an ordering property over a region that ended at the thing being ordered, so it could only fail if a string were absent.

⭐ **The measured version, and it is the thing to hold: switching one alert sender off entirely left THREE OF SIX tests green, in the file whose header promised every test had been watched failing against deliberately-broken real code.** ⚠️ **Be careful how you use that number** — it is one mutation, one file, one failure mode, and against all 17 tests in that file it is 18%. **It is not a repo-wide decoration rate and must not be quoted as one.**

## §4 — The discipline this lane is judged by

🔴 **A guard is only proven by watching it FAIL against deliberately-broken real code — and by the good-direction control almost nobody runs.**

**Both halves are mandatory here, because in one night FOUR instruments produced false results and every one was caught by a control rather than by care** *(the real count later turned out to be at least eleven)*: a merge-gate script that reported RED on known-good code · a token-grep proof that matched **a comment quoting the mutated string** · a mutation harness that spawned a shim it could not exec, so **all 24 mutations threw, were caught, and were recorded as RED** — caught only because a control mutation changing one comment word *also* reported RED · and CRLF silently voiding hand-typed find-strings, on two separate agents.

**⇒ Prove every mutation APPLIED before believing its verdict, and run a known-GOOD control alongside your known-BAD ones.** ⚠️ **Do your mutating in a throwaway worktree**, never in a tree anyone is working in.
