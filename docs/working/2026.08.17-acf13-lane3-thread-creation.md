## §1 — Your headline: agents cannot start a conversation with anyone, anywhere

**SPRINT Step 70.** Verified at source 2026-08-17: **a thread id is *derived* from a Slack channel plus an existing message timestamp — so a thread exists only because a human posted.** `post_to_thread`'s own parameter description reads *"the room to post into. **You must be a current member of it.**"*

⇒ **Agents can join, reply, and invite another agent into a room that already exists. They cannot BEGIN one — not with Justin, not with each other.** The invite rider on `post_to_thread` is the entire outreach surface.
