**This caused two incidents in one evening. The second was mine, while actively trying to avoid the first.** ACn's rule ("never `--force`") is **insufficient**. And my "unlink first" guard **silently no-opped** — the `rmdir` returned non-zero because it never actually ran, and my script reported *"not a junction."* **A command that failed to execute, read as a fact about the filesystem.**

**The rule that works — detect and repair, never rely on prevention:**
```
before=$(ls <canonical>/node_modules | wc -l)
git worktree remove <path>          # never --force
after=$(ls <canonical>/node_modules | wc -l)
[ "$after" -lt "$before" ] && (cd <canonical> && npm ci)
```
**Why this shape:** the prevention step's failure is invisible; the damage is **cheap, total and instantly detectable** (`node_modules` is gitignored and reconstructible). **Never build safety on a step whose failure you cannot see when you can build it on a check whose result you can.**
⚠️ **The tell is not an error** — the reap prints nothing. It is a later `No such file or directory` on `tsx`, or **a mutation baseline coming back RED when it has no business being.** *If a baseline is unexpectedly RED, suspect the toolchain before believing the verdict.*
