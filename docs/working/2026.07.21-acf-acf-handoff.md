## §8 — LESSONS — don't re-pay these

- **⭐ "I'll keep going with X" and then stopping — Justin sees this across many ACs and caught ACf doing it.** **Diagnosis:** the pull to end a turn is strongest right after composing a long, complete-*feeling* message — and **strongest of all when it ends in a question**, because asking creates a handoff expectation that swallows the stated intent. **⇒ The fix is ORDERING, not willpower: do the work FIRST, report in past tense.** If you catch yourself typing *"meanwhile I'll…"*, that is the signal to stop composing and go do it. **The message must never be the last action when you've declared continued work.**
- **⭐ Verify against the artifact, never the narrative.** It paid repeatedly: a sub-AC reported a fix-trip "in flight" that had already finished; a DC's routed note gave a corrected line number that was **itself wrong**; ACf1's "no `acf1/*` branches remain" was true *locally* while two stale **remote** branches survived. Each caught by looking, not reading. *(ACf1's own version: check `git branch -r`, not just local, when confirming a reap.)*
- **ROUTE an adjacent bug; FIX a defect your own change created.** Not the same thing — conflating them failed in both directions in one day (ACf deferred a trivial fix into a tracker row; a DC routed five references its own sweep had broken). **The test: broken BEFORE my change, or BY it?** Now in `CLAUDE.md`.
- **A recorded transcript must NOT be renumbered.** A *live* cross-reference gets corrected when your change moves it; a comment recording *real past output* must be left alone — editing it fabricates output that was never printed.
- **ACf1's push-back is usually RIGHT.** When his read of the live code disagrees with a design doc, **the code wins and the doc gets fixed.** Objection clock, not a gate — but vet each against the source before ruling.
- **This runtime punishes local reasoning almost perfectly.** Behavior is half `src/` and half the identity files; defects live in seams several hops from the changed line. **Every new guard test must be watched FAILING against deliberately-broken real code before it is trusted** — it has bitten this lane three times, including inside a test written to guard the previous instance of the same failure.
- **Reading cannot find an absence** (AC0's lesson, and it found Class Two). A missing `.limit()` has no wrong line to notice. **Break it and see whether anything complains.**
- **An under-specified subagent brief = the subagent self-lobotomizes, and it's AC's fault.** Justin: *"subagents love nothing more than lobotomizing themselves."*
- **Writing a literal NUL character into a file makes git treat it as binary** — ACf did this *while documenting the NUL bug*. Write the escape, never the character.
