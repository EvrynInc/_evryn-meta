## F. Lessons paid for tonight — add these to §8

- **🔴 `git add <paths>` then a bare `git commit` STILL SWEEPS another agent's staged work.** ACf did exactly this in `_evryn-meta` — staging two files by path, then committing, which absorbed **six** of another lane's already-staged file-moves. **`git add` scopes what YOU stage; `git commit` commits the WHOLE INDEX.** The fix that actually works is a **pathspec on the commit itself**: `git commit -F - -- <paths>`. Recovered with `git reset --soft HEAD~1` (which restores the index exactly), then re-committed by pathspec. **The standing rule says "stage by explicit path" — that is necessary and NOT sufficient, and this is the second distinct way it has proven insufficient.**
- **A "binary" file defeats GNU `diff`, not just git.** Verifying the canary sweep's change to `loop-signature.ts` required `diff -a`. Now moot — the NUL is gone — but the general lesson stands: when git says *Binary files differ*, your whole text-tooling layer is blind, not just git.

Check the ref, not the report.
